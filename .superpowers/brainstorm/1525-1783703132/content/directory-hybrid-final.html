Design contract

1

Navigation

“Store Directory” appears for every user in the workspace navigation and mobile drawer. The five-item bottom bar remains uncluttered.

2

Cards and actions

Live Mountain Time status, published hours, address, and schedule coverage. Call is primary; Message, Map, Schedule, and manager-only Edit remain available.

3

Responsive behavior

Two columns on wide screens, one column on phones. Mobile keeps 44px touch targets and collapses secondary actions without hiding information.

4

UI tuning

Shared card depth, spacing, status colors, focus states, typography, and button hierarchy are tightened across the app so the new page feels native—not bolted on.

If approved, I’ll write the spec and implementation plan, then build it with repeated desktop/mobile critique passes and tests.
